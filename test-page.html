Preformatted block

function fixationLength(length, intensity) {
  if (length <= 1) return length;
  return Math.min(Math.max(Math.floor(length * intensity), 1), length - 1);
}

WYSIWYG paragraph (pre-wrap, as Confluence and Notion emit)

Editors set white-space: pre-wrap on every paragraph so that spacing the author typed survives a round trip. This text still reflows normally when the window is resized, so it is ordinary prose and must be highlighted -- treating pre-wrap as preformatted discards the entire article.
